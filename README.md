# Mask Library Repairs

Each release asset is a repaired copy of a 3D-printable mask or helmet model listed in the [Mask & Helmet Library gallery](https://stephens-mask-helmet-library.stephenbobianesq.chatgpt.site). The original model's title, source and licence are recorded in its gallery entry. Original files are preserved; repaired copies are additional downloads.

Repairs include watertight and manifold mesh fixes and recorded unit corrections, verified with the same audit code used for the gallery. Each repair report retains before/after mesh statistics, operations, tool versions, byte size and SHA-256. Copies with significant geometry changes are marked for inspection in the gallery. Digital mesh verification does not establish physical fit or printer readiness.

One release is published per repair batch. Asset names identify the gallery entry and original file stem. This repository does not change or grant rights to the underlying models; consult each gallery entry for the original licence and source.
